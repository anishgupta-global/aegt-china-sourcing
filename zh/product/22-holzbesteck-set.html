产品描述

自欧盟禁止一次性塑料餐具以来，木质餐具成为工地餐饮、封顶宴和食堂的必备品。

更多

优质餐具打磨后无木刺，口感中性，切软食物时不折断，包装干燥无霉变。德国专业买家期望使用有 FSC 或 PEFC 认证、来源可追溯的木材，并要求提供符合法规 (EC) 1935/2004 的食品接触证明。涂层或蜡只有在不属于一次性塑料指令所指的塑料时才允许使用。

内部 · 备注

需向供应商索取

  • 符合法规 (EC) 1935/2004 的符合性声明，以及认可实验室出具的食品接触检测报告（需明确写出木材、蜡或涂层）。
  • 书面索取树种（桦木）、原产国，以及合法性和无毁林证明（按 TARIC 提示核查 EUDR/FLEGT）。
  • 有效的 FSC 或 PEFC 监管链证书；到数据库核对许可证编号。
  • 声明未使用塑料涂层，避免产品被归入塑料餐具禁令范围。
  • 检查样品的无木刺性、切割时的抗折强度、气味、含水率和霉变情况。
  • 确认制造商身份（工厂还是贸易商）、卫生体系证书（如 ISO 22000），以及包装上的德文标识。
