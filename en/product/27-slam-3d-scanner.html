Description

The SLAM handheld scanner captures buildings, plant rooms and basement areas in minutes as a dimensionally accurate point cloud and so replaces time-consuming manual …

More

measurement before strip-out, demolition and refurbishment. The data flows as E57, LAS or PLY into CAD and BIM software so that quantities, openings and existing conditions can be planned reliably. Professional users in Germany expect laser class 1, a traceable accuracy protocol, rugged construction from IP54 and German-language software support. For use in asbestos areas, decontaminability under TRGS 519 must be clarified with the manufacturer.
